The tool now searches Codex, OpenCode, and Hermes history as well as Claude Code, it is much faster on large histories, and it is published as three packages. The GitHub repository was renamed from `search-claude-history` to `search-clanker-history`, and old links redirect to the new name.

## Packages and commands

| Package | Command | Searches by default |
| --- | --- | --- |
| `search-clanker-history` (new) | `search-clanker-history` | Every agent that has history: [Claude Code](https://docs.anthropic.com/en/docs/claude-code), [Codex](https://github.com/openai/codex), [OpenCode](https://github.com/anomalyco/opencode), and [Hermes](https://github.com/NousResearch/hermes-agent) |
| `search-claude-history` | `search-claude-history` | Claude Code only, as before |
| `search-codex-history` (new) | `search-codex-history` | Codex only |

`search-clanker-history` contains all the code. The other two packages contain no code of their own: each installs `search-clanker-history` at the same version and starts it with a different default. Every package installs exactly one command, named after the package, so any mix of the three can be installed together without `--force`, and removing one never removes another's command.

The short command `sch` is no longer installed by any package. If you use it, make it a shell alias or a link to the command you installed, for example `ln -s ~/.local/bin/search-clanker-history ~/.local/bin/sch`.

## Choosing which agents are searched

Which agents a plain search covers comes from, in order: `--agent AGENT` for that search, the default you saved, the installed `search-claude-history` or `search-codex-history` package, and otherwise every agent that has history. Change the saved default at any time, with no reinstall:

```sh
search-claude-history --default-agents                 # show the default and where it is saved
search-claude-history --default-agents claude codex    # search Claude Code and Codex
search-claude-history --default-agents all             # search every agent that has history
search-claude-history --default-agents reset           # back to the package's own default
```

The choice is stored in `~/.config/search-history/config.json` (under `$XDG_CONFIG_HOME` when that is set, and in `%APPDATA%\search-history\config.json` on Windows) and is shared by all three packages. `--default-agents` cannot be combined with a search. A damaged settings file, an empty list, or an unknown agent name produces one warning naming the file, and the search still runs. When the default hides another agent's history, a search that finds nothing says which agents were not searched.

## Upgrading from `search-claude-history` 0.1.x

`uv tool upgrade search-claude-history` keeps searching only Claude Code, and `--default-agents all` adds the other agents. The `sch` command is no longer installed, and the `search_claude_history` Python module no longer contains code, because the code now lives in `search_clanker_history`. Every result header now includes the agent name, for example `── 2026-02-17 05:35 | claude | -code-rb | session:720d82ef ──`, so anything that parses the old header needs the extra field. Python 3.10 or newer is now required.

## Other changes

- `--agent` limits a search to one or more agents, and `-n N` returns only the N most recent matches, still printed oldest first.
- Searches are much faster on large histories. On 15 GB of history a common word takes about 3 seconds instead of 13, a search limited with `--since 1d` takes under 1 second instead of 12, and `-n 20` takes about 1 second. `-A` and `-B` context lines no longer reread the whole file for each match.
- The optional `ripgrep` extra installs the [ripgrep](https://github.com/BurntSushi/ripgrep) binary for machines that do not have it.
- A pattern that ripgrep rejects but Python accepts, such as a lookahead, used to return nothing. It now falls back to a slower scan that finds the matches.
