This release fixes searches that use a lookahead or another pattern [Hyperscan](https://www.hyperscan.io/) cannot compile, when the optional `hyperscan` extra is installed. The same version is published as `search-clanker-history`, `search-claude-history`, and `search-codex-history`.

sch falls back from [ripgrep](https://github.com/BurntSushi/ripgrep) to its own scanner when ripgrep is missing or rejects a pattern. With hyperscan installed, that scanner searched for a pattern hyperscan rejected, such as `needle(?= in session 1)`, as literal text, so it found nothing. It now uses Python's regular expressions for such patterns and hyperscan for the rest.
