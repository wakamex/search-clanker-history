This release makes searching one session fast, changes what `-t user` lists for Claude Code, and finds Devin sessions in a moved data folder. The same version is published as `search-clanker-history`, `search-claude-history`, and `search-codex-history`.

- `-s SESSION` now reads only that session's files for every agent whose file names carry the session id, where it used to list and often read every agent's history. On a busy host one Claude Code session's user messages took 12.8 seconds across all agents and now take about 3, most of it reading that session's own 86 MB file.
- `-t user` now lists only messages that start a turn. Claude Code writes records into the user's side that start none: interrupt notices, slash-command records and their output, lines it marks `isMeta`, and tool results with a reminder attached. These are now shown only with `--tools`, like other tool records. Task notifications and messages delivered by other agents stay. Custom slash commands that prompt the model are hidden by the same rule.
- Devin CLI sessions are found under `$XDG_DATA_HOME/devin/cli/sessions.db`, or under `$DEVIN_SESSIONS_DIR/cli/sessions.db` when that is set, as Devin itself does.
