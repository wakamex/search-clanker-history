This release makes searches faster, mainly by searching every agent at once. The same version is published as `search-clanker-history`, `search-claude-history`, and `search-codex-history`.

- A plain search now runs each agent in its own thread while the first agent's results print, where it used to go through the agents one after another. A rare phrase across all agents fell from about 14 seconds to about 5 on a busy host. Without [ripgrep](https://github.com/BurntSushi/ripgrep) the agents still run in turn.
- Claude Code history is searched in larger batches, which start at 256 files and grow to 1,024, so a common word's first results still print early.
- Antigravity transcripts are found directly instead of by walking every conversation folder, which took about 2 seconds.
- Cursor chats are checked with SQLite, over message records only. Plain text is matched in parallel threads, and a rare phrase across all chats takes about a third of a second instead of 2.
- When the reader of sch's output closes early, as `head` does, sch exits at once.
